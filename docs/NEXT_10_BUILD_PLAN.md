# MedCompass Next 10 Build Plan

This batch is focused on compounding the work already in place: source-aware reading, fake AI foundations, planner-linked practice exams, saved attempts, and the study atlas.

## 1. Living build plan

Create this plan so the next batch of work has an explicit product direction, not just scattered UI tweaks.

## 2. Reader → Chat handoff

Let a student highlight text in a PDF and send that context into the main Chat page, instead of trapping the AI interaction inside the reader modal.

## 3. Richer Chat context

Make Chat accept launched context from elsewhere in the app: selected text, source title, page number, and topic. This keeps future AI integration clean.

## 4. Library readiness overview

Add a simple source-readiness dashboard to Library so students can see what is uploaded, extracted, pending, or needing attention.

## 5. Home practice pulse

Surface the most relevant practice-exam state on the homepage: latest attempt, generated papers, and a CTA back into Practice.

## 6. Practice attempt history

Show completed attempts for the selected paper so the feature starts to feel durable, not just “answer boxes on a page.”

## 7. Better attempt controls

Add reset/reveal controls while sitting a paper, making practice mode more forgiving and easier to demo.

## 8. Topic study brief

Add a lightweight topic-level brief that summarizes source/note/card/exam readiness and gives clear next actions.

## 9. AI standards visibility

Expose the fake-AI standards/templates in the Chat UI so students can understand what MedCompass will ask the model to produce later.

## 10. Current-state docs refresh

Update product/current-state docs so future work stays aligned with the new Chat, Practice, attempts, and source-aware study flow.
