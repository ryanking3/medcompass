# Next 10 build plan — round 2

This batch tightens the fake-AI foundations and makes the existing study loop feel more connected before real model integration is added.

## 1. Chat citation persistence

When a student sends PDF context into Chat and saves a fake AI note or card, the saved study object should retain the source/page context instead of becoming detached.

## 2. Chat source-readiness empty states

The Chat page should clearly explain when it has no usable sources yet and route students back to Library to upload or prepare PDFs.

## 3. Inline Library preparation controls

Students should be able to prepare or retry extraction from the Library list itself, without opening the full reader first.

## 4. Practice answer review

Saved practice attempts should show the student's submitted answers, not only the attempt summary.

## 5. Practice-to-Chat handoff

A completed or selected practice paper should be able to open Chat with a focused review prompt.

## 6. Topic-to-Chat handoff

Topic pages should provide a quick path into Chat with the topic context attached.

## 7. Planner-to-Practice bridge

The planner should point students toward generating a mock paper from an exam, keeping exam prep connected to practice.

## 8. Reader page bookmarks

The PDF reader should support quick in-session page bookmarks for shortlisting useful diagrams, tables, or explanations.

## 9. Documentation refresh

Update the current-state docs and README so shipped fake-AI foundations, planner/practice flows, and reader behaviour stay accurate.

## 10. Verification and push

Run typecheck/lint, commit coherent changes as they land, and push the full batch to GitHub.
